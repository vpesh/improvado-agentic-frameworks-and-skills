# Knowledge Framework → Notion Skill - Release Log

## v1.0.0 (2025-11-25)

**Initial Release**

### Features
- Markdown to Notion blocks conversion
- Full Mermaid diagram support with auto-detection
- Content limit handling (2000 chars, 100 blocks)
- Batching for large documents
- JSON output format for API integration

### Supported Elements
- Headings (H1-H3)
- Paragraphs with text splitting
- Bulleted and numbered lists
- Code blocks with language detection
- Mermaid diagrams (auto-rendered by Notion)
- Quotes
- Dividers

### Integration
- Designed for Windmill + Headless Droid (droid exec)
- JSON output compatible with Notion API
